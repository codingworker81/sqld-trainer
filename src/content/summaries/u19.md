# 19. 정규식 메타문자

Oracle의 `REGEXP_LIKE`, `REGEXP_REPLACE`, `REGEXP_INSTR`, `REGEXP_SUBSTR`, `REGEXP_COUNT` (13단원)에서 패턴(pattern) 인자에 쓰는 정규식 메타문자를 정리한다. Oracle SQL의 정규식은 POSIX 표준(IEEE 1003.2)을 기반으로 하며, Perl에서 쓰는 일부 확장 표기(`\d`, `\w`, `\s` 등)도 함께 지원한다. (근거: Oracle 공식 문서 "Using Regular Expressions in Database Applications", "Pattern-matching Conditions" — docs.oracle.com)

---

## 1. 기본 메타문자

| 메타문자 | 의미 | 예시 |
| --- | --- | --- |
| `.` | 임의의 한 문자(기본적으로 줄바꿈 제외) | `a.c` → `abc`, `acc` 등과 매칭 |
| `*` | 바로 앞 문자가 0회 이상 반복 | `ab*c` → `ac`, `abc`, `abbc` |
| `+` | 바로 앞 문자가 1회 이상 반복 | `ab+c` → `abc`, `abbc` (단 `ac`는 불일치) |
| `?` | 바로 앞 문자가 0회 또는 1회 | `ab?c` → `ac`, `abc` |
| `{n}` | 정확히 n회 반복 | `a{3}` → `aaa` |
| `{n,}` | n회 이상 반복 | `a{2,}` → `aa`, `aaa`, `aaaa` ... |
| `{n,m}` | n회 이상 m회 이하 반복 | `a{2,4}` → `aa`, `aaa`, `aaaa` |
| `[ ]` | 괄호 안 문자 중 하나(문자 집합) | `[abc]` → `a`, `b`, `c` 중 하나 |
| `[^ ]` | 괄호 안 문자를 제외한 문자(부정) | `[^abc]` → a, b, c가 아닌 문자 |
| `[-]` | 괄호 안에서 연속된 문자 범위 지정 | `[a-z]` → a부터 z까지 소문자 중 하나 |
| `( )` | 그룹 지정(하위식 캡처) | `(ab)+` → `ab`, `abab` 등 |
| `\|` | 둘 중 하나(OR, 대체) | `cat\|dog` → `cat` 또는 `dog` |
| `\` | 이스케이프 문자(메타문자를 리터럴로) | `\.` → 마침표 문자 자체 |

⚠️ `*`, `+`, `?`, `{n}`, `{n,}`, `{n,m}`은 모두 기본적으로 탐욕적(greedy) 매칭을 한다. 즉 가능한 한 가장 긴 문자열에 매칭을 시도한다.

---

## 2. 앵커(anchor)

| 메타문자 | 기본 동작 | `m`(multiline) 옵션 적용 시 |
| --- | --- | --- |
| `^` | 전체 문자열의 시작 | 각 줄(line)의 시작 |
| `$` | 전체 문자열의 끝 | 각 줄(line)의 끝 |

- `^abc` → `abc`로 시작하는 문자열
- `xyz$` → `xyz`로 끝나는 문자열
- ⚠️ match_param에 `'m'`을 주면 `^`, `$`가 문자열 전체가 아니라 줄바꿈으로 구분된 각 줄의 시작/끝을 의미하게 된다(5절 참고).

---

## 3. 문자 클래스 (Perl 확장 표기)

Oracle은 POSIX 표준 외에 Perl에서 널리 쓰는 아래 표기도 지원한다.

| 표기 | 의미 | POSIX 동등 표현 |
| --- | --- | --- |
| `\d` | 숫자 한 글자(0~9) | `[[:digit:]]` |
| `\D` | 숫자가 아닌 한 글자 | `[^[:digit:]]` |
| `\w` | 단어 문자(영문자, 숫자, `_`) | `[[:alnum:]_]` |
| `\W` | 단어 문자가 아닌 글자 | `[^[:alnum:]_]` |
| `\s` | 공백류 문자(스페이스, 탭, 줄바꿈 등) | `[[:space:]]` |
| `\S` | 공백이 아닌 문자 | `[^[:space:]]` |

예시: `\d{2,4}` → 2~4자리 숫자, `\w+` → 단어 문자 1개 이상 연속.

---

## 4. POSIX 문자 클래스

대괄호 두 겹 `[[:클래스명:]]` 형태로 쓴다(바깥 `[ ]`는 문자 집합, 안쪽 `[:...:]`가 POSIX 클래스 이름).

| 클래스 | 의미 |
| --- | --- |
| `[:alpha:]` | 알파벳 문자 (a-z, A-Z) |
| `[:digit:]` | 숫자 (0-9) |
| `[:alnum:]` | 알파벳 + 숫자 |
| `[:upper:]` | 대문자 |
| `[:lower:]` | 소문자 |
| `[:space:]` | 공백류 문자 |
| `[:punct:]` | 구두점·특수문자 |
| `[:cntrl:]` | 제어 문자 |
| `[:print:]` | 출력 가능한 문자(공백 포함) |
| `[:graph:]` | 출력 가능한 문자(공백 제외) |
| `[:blank:]` | 스페이스와 탭 |
| `[:xdigit:]` | 16진수 숫자 (0-9, a-f, A-F) |

예시: `REGEXP_LIKE(col, '^[[:upper:]]+$')` → 전체가 대문자로만 이루어진 문자열인지 검사.

⚠️ POSIX 클래스는 반드시 `[ ]` 안에서 `[:클래스명:]` 형태로 써야 한다. `[:alpha:]`만 단독으로 쓰면 안 되고 `[[:alpha:]]`처럼 바깥 대괄호가 한 번 더 필요하다.

---

## 5. match_param (매칭 옵션)

`REGEXP_LIKE`, `REGEXP_REPLACE`, `REGEXP_INSTR`, `REGEXP_SUBSTR`, `REGEXP_COUNT` 모두 마지막 인자로 `match_param` 문자열을 받는다.

| 옵션 | 의미 |
| --- | --- |
| `i` | 대소문자를 구분하지 않음 |
| `c` | 대소문자를 구분함(DB 설정과 무관하게 강제) |
| `n` | `.`(dot)이 줄바꿈 문자까지 포함해서 매칭(기본은 줄바꿈 제외) |
| `m` | 여러 줄 모드: `^`, `$`가 문자열 전체가 아니라 각 줄의 시작/끝을 의미 |
| `x` | 패턴 안의 공백 문자를 무시 |

- ⚠️ `i`와 `c`처럼 상반된 옵션을 동시에 쓰면(`'ic'`), 마지막에 쓴 문자가 우선 적용된다.
- 예시: `REGEXP_LIKE(last_name, '([aeiou])\1', 'i')` → 대소문자 구분 없이 모음이 연달아 반복되는 이름 검색.

---

## 6. 그룹과 역참조(Backreference)

- `( )`로 묶은 부분은 "하위식(subexpression)"으로 캡처되며, 패턴 안에서 `\1`~`\9`로 그 캡처된 값을 다시 참조할 수 있다.
- 패턴 예시: `(abc|def)xy\1` → `abcxyabc`, `defxydef`는 매칭되지만 `abcxydef`는 매칭되지 않는다(첫 그룹이 캡처한 값과 \1이 반드시 같아야 하므로).
- ⚠️ 역참조는 패턴 안에서만 아니라 `REGEXP_REPLACE`의 치환 문자열(replace_string)에서도 쓸 수 있다.
  ```sql
  SELECT REGEXP_REPLACE(
    'John Quincy Adams',
    '^(\S+)\s(\S+)\s(\S+)$',
    '\3, \1 \2'
  ) FROM dual;
  -- 결과: 'Adams, John Quincy'
  ```
- 연속된 두 글자가 같은지 검사하는 대표 패턴: `(\w)\1` → 같은 단어 문자가 2번 연달아 나오는 부분과 매칭.

## 7. LIKE와 REGEXP_LIKE 비교

| 구분 | `LIKE` | `REGEXP_LIKE` |
| --- | --- | --- |
| 와일드카드 | `%`(0개 이상), `_`(정확히 1개) 2종류뿐 | 메타문자·수량자·앵커·문자클래스 등 정규식 전체 |
| 패턴 표현력 | 단순 패턴만 가능 | 복잡한 패턴(반복 범위, 대체, 그룹, 역참조 등) 가능 |
| 특수문자 이스케이프 | `ESCAPE` 절 필요(`LIKE '50\%' ESCAPE '\'`) | `\`로 메타문자 이스케이프 |
| 대소문자 구분 | DB/컬럼 정렬(collation) 설정을 따름 | `match_param`의 `i`/`c`로 직접 제어 가능 |

- ⚠️ `LIKE`로는 "숫자가 정확히 3자리인지", "같은 문자가 반복되는지" 같은 조건을 표현할 수 없다. 이런 경우에는 `REGEXP_LIKE`가 필요하다.
- 예: 우편번호가 숫자 5자리인지 검사 → `REGEXP_LIKE(zip, '^[[:digit:]]{5}$')`는 가능하지만, `LIKE '_____'`는 숫자인지 여부까지는 검사하지 못하고 글자 수만 검사한다.
